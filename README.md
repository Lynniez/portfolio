## Description
My personal portfolio website. It shows who I am, my skills, my projects, my education and how to contact me. It works on desktop, tablet and phone.

## Technologies
HTML5, CSS3, JavaScript. Edited in Visual Studio Code and tested with Chrome DevTools.

## Features
- Sections: Home, About, Skills, Projects, Contact
- Responsive layout with a menu button on small screens
- Skills and projects are created from JavaScript arrays
- Project filter buttons
- Contact form with validation and a confirmation message
- Current section is highlighted in the menu
